# 🚀 How to Run the AI Employee Demo

This guide will help you show your project to your teachers.

## 1. Start the "Brain" (The Orchestrator)
The AI code runs in a terminal window. To start it:
1. Open the `Hackathon_0` folder on your Desktop.
2. Double-click the **`start_orchestrator.bat`** file.
3. A black window (terminal) will open. You will see:
   - "Orchestrator started..."
   - "[RALPH WIGGUM] Logging Heartbeat..."
   - This means the AI is now ALIVE and watching your folders.

## 2. Open the "Dashboard" (Obsidian)
1. Open Obsidian and select the `Hackathon_0` vault.
2. Open **`Dashboard.md`**.
3. You will see the **System Health** section updating its "Last Heartbeat" every minute.

## 3. The Live Demo (Show your Teachers!)
To show how the AI works:
1. In Obsidian (or your file manager), go to the **`Needs_Action`** folder.
2. Create a new Note (e.g., `test_task.md`) and write some text in it.
3. **Watch the Terminal (Black window)**: Within 10 seconds, it will say "Found item needing action".
4. **Watch Obsidian**: 
   - The file will disappear from `Needs_Action`.
   - A new plan will appear in **`Plans/`**.
   - An approval request will appear in **`Pending_Approval/`**.
5. Move the file from `Pending_Approval` to **`Approved`**.
6. **Watch the Dashboard**: A new log will appear under "Recent Activity"!
